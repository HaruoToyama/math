# 図形ラボ

中学校数学の図形を、頂点を動かしながら学べるブラウザアプリです。

## 使い方

依存関係やビルドは不要です。`index.html` をブラウザで開くか、リポジトリのルートで次を実行します。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` にアクセスしてください。

## できること

- 三角形・四角形の頂点をドラッグし、辺の長さ、角度、周の長さ、面積をリアルタイムに確認
- 三角形の内角の和が 180°、四角形の内角の和が 360° になることを検証
- 平行移動、線対称移動、180°回転した合同な図形を元の図形と比較
